# Liverpool Gaming — النسخة التشغيلية الجديدة

- [ ] بدء الجلسة يختار نوع الجهاز PS4 أو PS5 ثم الشاشة المتاحة، بدون خيار تبديل الشاشة داخل النموذج.
- [ ] تهيئة الأجهزة الجديدة تلقائياً: 7 أجهزة في كل فرع، و8 أجهزة في فرع تشيلسي، مع وجود النوع PS4/PS5 لكل جهاز.
- [ ] بدء كل جلسة جديدة باسم "جلسة بوقت" عند اختيار مدة محددة، مع حساب المدة والتكلفة بدقة وعدم استخدام تسمية "جلسة موقوتة".
- [ ] حذف بيانات التجارب من التخزين السحابي والمحلي عند أول تشغيل نظيف، والبدء بدون جلسات أو موظفين أو حركة مالية أو مخزون تجريبي.
- [ ] ربط بيانات التشغيل بالمخزن السحابي في Supabase عبر خادم التطبيق، مع استمرار نسخة LocalStorage عند انقطاع الاتصال.
- [ ] تسجيل حضور الموظف وانصرافه كلٌّ بوقت مستقل، وعرض وقت الوصول ووقت المغادرة للمالك بوضوح.
- [ ] توثيق الجلسة: من بدأها، وقت البدء، طلبات الكافتيريا ومن أضافها ومتى، من غيّر الأذرع أو نوع الجهاز ومتى، ومن أنهى الجلسة ومتى.
- [ ] تبسيط سجل تغييرات الجلسة وتسمياته، وعرض حساب الوقت والتكلفة حسب الفترات دون وصف مضلل.
- [ ] تحسين عرض الجلسات والأسعار على الشاشات الصغيرة وتقليل ازدحام النوافذ والجداول.
- [ ] تشغيل lint والاختبارات والبناء، ثم مراجعة اتصال Supabase قبل تجهيز النسخة المنشورة.
